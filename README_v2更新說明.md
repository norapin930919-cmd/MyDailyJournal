# 我的每日手帳 v2

## 新增功能
- 今日情緒增加到 18 種
- 情緒可以多選
- 同一情緒可以重複點選，會顯示 ×2、×3…
- 長按情緒可減少一次
- 前一天未完成的待辦會自動帶到隔天
- 每日評語：依日記、情緒與完成事項整理較完整的回饋
- 每週總結：星期一～星期日，整理日記天數、情緒、待辦完成率、閱讀、靈感與完成事項
- React Native 已更新為 Expo 54 建議版本 0.81.5

## 如何更新你原本的專案（最簡單）
1. 先把舊的 MyDailyJournal_Expo 資料夾保留當備份。
2. 解壓縮這個 v2 壓縮檔。
3. 在 v2 的 MyDailyJournal_Expo_v2 資料夾開 PowerShell。
4. 執行：
   npm.cmd install
5. 再執行：
   npx.cmd expo start --lan

如果 LAN 連線被 Windows 防火牆擋住，請允許 Node.js JavaScript Runtime 通過「私人網路」。

## 關於「每日評語」
目前 v2 的評語是在手機本機依文字內容做智慧整理，不需要帳號、不需要 API、不需要付費，也不會把日記上傳到外部服務。

如果之後想要真正由 AI 逐篇閱讀並給出更深入、每次都不同的長篇回饋，可以再升級成 AI 版；那一版會需要網路與 AI 服務。
